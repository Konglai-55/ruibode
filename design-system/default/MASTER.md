# 瑞卜德教育赛事报名平台 · 设计规范

**Updated:** 2026-08-15  
**Direction:** 中文教育机构赛事官网 / 信息型报名门户  
**Design dials:** Variance 3/10 · Motion 2/10 · Density 7/10

## 1. 设计目标

- 让赛事、人员、战队、缴费和审核信息成为视觉主体。
- 保持教育机构官网的正式、可靠和可追溯感，避免企业 SaaS 营销页气质。
- 前台、个人中心和管理端使用同一套品牌、控件与信息密度。
- 不用英文装饰标题、营销口号、虚构数据或无意义的视觉装饰。

## 2. 品牌与色彩

| 角色 | 值 | 用途 |
|---|---|---|
| 品牌主色 | `#C8152E` | 主按钮、当前导航、标题标线、关键链接 |
| 品牌深色 | `#A90F25` | 悬停、按下状态 |
| 正文 | `#202124` | 标题与主要内容 |
| 次级文字 | `#5F6368` | 说明、时间、辅助信息 |
| 页面背景 | `#F4F4F2` | 全局背景 |
| 卡片背景 | `#FFFFFF` | 内容区域、表单、表格 |
| 弱背景 | `#F5F5F3` | 表头、事实项、只读区域 |
| 边框 | `#BFC2C6` / `#DEDEDE` | 控件与区域分隔 |
| 成功 | `#096B46` | 已通过、未开始；必须同时显示文字 |
| 警告 | `#8A4B00` | 待审核；必须同时显示文字 |
| 错误 | `#B42318` | 驳回、删除、校验错误 |

绿色只表达成功或可用状态，不作为主 CTA。状态不能只靠颜色区分。

## 3. 字体与排版

- 字体：`Microsoft YaHei`, `PingFang SC`, `Noto Sans CJK SC`, Arial, sans-serif。
- 正文：16px / 1.6；移动端不得低于 16px。
- 页面标题：30px / 700；模块标题：24px；卡片标题：18–19px。
- 标题依靠字号、字重、留白和品牌红标线建立层级，不使用全大写英文 eyebrow。
- 数据列使用等宽数字特性；长赛事名允许换行，不强制截断。

## 4. 布局与间距

- 桌面内容宽度：1180px；页面边距：16px；移动端边距：12px。
- 主要断点：375 / 620 / 820 / 1080 / 1440。
- 使用 4/8px 间距节奏，常用间距为 8、12、16、20、24、32、40、48。
- 前台赛事列表以 3 / 2 / 1 列响应式卡片展示。
- 个人中心桌面使用 252px 侧栏，820px 以下切换为横向导航。
- 表格优先用于桌面高密度数据；620px 以下切换为信息卡片。

## 5. 视觉语言

- 圆角仅 2–6px；品牌 Logo 保持原始圆形。
- 普通卡片无阴影，以 1px 边框和背景分层；阴影仅用于下拉菜单、模态框和 Toast。
- 禁止装饰性渐变、玻璃模糊、大面积光晕、漂浮指标卡、过度胶囊化。
- 卡片悬停只改变边框或背景，不上浮、不缩放、不造成布局变化。
- 图标统一使用现有线性 SVG 图标，不使用 Emoji。
- 瑞卜德圆形 Logo 是主品牌标识，必须保留；RECF 标识作为联合 Logo，与主 Logo 以分隔线和规范留白并列展示，不得替换主 Logo。
- 未提供真实赛事图片时使用后台现有封面占位，不生成看似真实的虚构现场照片。

## 6. 组件规范

### 导航

- 白底、1px 下边框、高度 72px。
- 当前入口用品牌红文字和 2px 底线表示。
- “活动报名”是唯一报名导航入口，包含赛事、志愿者和观赛报名。
- 登录后战队管理与我的比赛位于用户菜单/个人中心，不重复出现在主导航。

### 按钮

- 高度至少 44px，圆角 4px。
- 每屏原则上仅一个品牌红主按钮，其余使用描边次按钮。
- 删除/驳回使用危险色，与主操作保持间距。
- 按下以亮度变化反馈，不使用位移或缩放。

### 输入与上传

- 输入框高度至少 46px，圆角 3px，始终显示可关联的标签。
- 聚焦使用品牌红边框与 3px 半透明外环。
- 错误显示在字段下方并说明如何修复。
- 上传区域使用虚线边框与中性灰背景，不做悬浮投影。

### 登录验证

- 登录只校验用户名/注册邮箱与密码；凭据正确后直接创建会话，不再要求图形验证码或邮箱验证码。
- 注册和找回密码继续使用图形验证码与 6 位邮箱验证码，邮箱验证码有效期 10 分钟且仅可使用一次。
- 找回密码分为获取验证码、验证并设置新密码两步；注册手机号只作为账户资料保存，不作为验证渠道。

### 状态

- 状态标签为 3px 小圆角矩形，禁止胶囊形。
- 文本必须完整显示并保持单行，移动端不可挤成逐字换行。

### 卡片与表格

- 卡片：白底、1px 灰边框、4px 圆角、无阴影。
- 表格：中性灰表头，13px 加粗标签，行间使用清晰分隔线。
- 管理端摘要卡可用 4px 顶部色条表达类别，但不使用渐变或发光。

### 模态框

- 桌面 6px 圆角，移动端底部面板仅顶部 8px 圆角。
- 遮罩 40–60% 黑色；必须有关闭按钮并支持 Escape。
- 模态框是编辑、确认和查看详情容器，不作为主导航。

### 底栏

- 深中性灰底，顶部 4px 品牌红标线。
- 只包含品牌说明、报名入口、联系方式和资料用途说明。
- 禁止营销型 CTA 卡、发光背景、统计数字和泛化口号。

## 7. 文案原则

- 写具体动作与结果，例如“上传参赛费支付凭证”“等待管理员审核”。
- 避免“一站式赋能”“从创建到赛场”等抽象营销文案。
- 不虚构实时名额、赛事热度、完成率或机构背书。
- 空状态提供明确下一步，不只写“暂无数据”。

## 8. 动效与可访问性

- 微交互 150–220ms；仅动画 opacity / transform。
- 支持 `prefers-reduced-motion`。
- 所有触控目标至少 44×44px；键盘焦点必须可见。
- 正文对比度至少 4.5:1；信息不得只通过颜色传达。
- 保留跳过导航链接、语义标签、图片 alt、表单 label 和 aria-live 提示。
- 办赛通知使用所见即所得编辑器，编辑区即为最终排版效果；底层自动转换为 Markdown 存储，前台按正式通知版式渲染。
- 验收尺寸：375、768、1024、1440，并检查移动端横屏。

## 9. 交付前检查

- [ ] 前台、账户端、管理端视觉一致
- [ ] 赛事 / 志愿者 / 观赛列表与详情均可访问
- [ ] 状态文字在窄屏不逐字换行
- [ ] 输入、按钮、导航满足键盘与触控尺寸要求
- [ ] 375 / 768 / 1024 / 1440 无水平滚动和遮挡
- [ ] 登录、注册、报名、审核与上传流程测试通过
